# Privacy Policy

Effective date: 2026-01-03

This extension does not collect, store, or transmit personal data to the developer.

It may send ON/OFF signals and meeting context (service name and, if configured, the meeting URL) to network endpoints that the user explicitly configures (e.g., Home Assistant, smart devices).
The extension does not scan the local network and does not send data to any third-party servers by default.

Data retention: No data is collected or retained by the developer.

Contact: Please use the project issue tracker for privacy questions: https://github.com/mveplus/onair-meeting-trigger/issues
